## Key Discovery: Epic 7 Tenant Mapping Storage

**Question Raised:** Where should tenant-to-space mappings be stored?

**Investigation:** Reviewed CIPP's Hudu module patterns

**Finding:** Hudu uses **Azure Data Table Storage** via CIPP's extension framework:

| Component | Hudu Pattern | Confluence Equivalent |
|-----------|--------------|----------------------|
| **Table** | `CippMapping` | `CippMapping` (same) |
| **Partition Key** | `'HuduMapping'` | `'ConfluenceMapping'` |
| **Row Key** | Tenant ID | Tenant ID |
| **Properties** | `IntegrationId`, `IntegrationName` | `SpaceKey`, `SpaceName` |

**Reference Files:**
- `Modules/CippExtensions/Public/Hudu/Get-HuduMapping.ps1`
- `Modules/CippExtensions/Public/Hudu/Set-HuduMapping.ps1`
- `Modules/CippExtensions/Public/Extension Functions/Get-ExtensionMapping.ps1`

**Impact:** Story 7.2 (Tenant-Space Mapping Management) has clear pattern to follow - no architectural guesswork needed.
